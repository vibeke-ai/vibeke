Vibeke 0.25.0 adds bulk image deletion to the command palette.

## Delete saved images and screenshots

Press `prefix+:` to open the command palette. Choose **Delete all images and screenshots**, then confirm once. Vibeke removes saved images and screenshots from the sidebar and gallery on each connected host. It keeps screenshots that are part of an accepted review.

## Install or upgrade

The host CLI supports macOS 13 or later on Apple silicon and Intel. It also supports Linux on x86_64 and ARM64. Install `minisign` with your package manager, then run:

```sh
curl -fsSL https://vibeke.dev/install.sh | VIBEKE_VERSION=0.25.0 sh
```

Start `vibeke` in your project directory. If you already use Vibeke, run `vibeke update`.

## Browser and phone

Open [app.vibeke.dev](https://app.vibeke.dev). On your host, open **Devices** in the Vibeke terminal and select **Pair a phone**. You can also run:

```sh
vibeke gateway pair
```

Scan the code. Check the device fingerprint on both devices.

## Desktop updates

Open **Check for Updates…** in the desktop app to update a macOS, Windows EXE, or Linux AppImage installation. For a Linux DEB installation, download the new DEB. Windows may ask you to approve the installer because it has no publisher signature.
