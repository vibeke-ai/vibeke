Vibeke 0.24.0 brings Codex sessions on the shared background server into the Conversation view. It also restores Claude Code transcripts in new panes.

## Codex conversations

Type `codex` in a new Vibeke pane. Open **Conversation** in the desktop or browser app to read its messages. Each pane follows the thread that Codex opens there. Two panes can use the same project directory. Starting a new thread with `/new` switches the view to that thread.

Vibeke can use the shared background server in Codex 0.169.0 or later. Start the server or enable the Codex setting `daemon_auto_start`. The options `--worktree`, `--profile` (`-p`), and `--oss` use a separate Codex process for the pane.

When you use the shared server, answer approvals in the Codex terminal. Use `codex --no-daemon` for pane hooks and inbox approvals.

When you fork a conversation, open the Codex terminal to see the earlier messages. The Conversation view shows new messages in the fork.

## Claude Code conversations

A new pane starts a separate Claude Code session even if you started Vibeke from inside Claude Code. Claude can save its transcript, so its messages are available in the Conversation view.

## Install or upgrade

The host CLI supports macOS 13 or later on Apple silicon and Intel. It also supports Linux on x86_64 and ARM64. Install `minisign` with your package manager, then run:

```sh
curl -fsSL https://vibeke.dev/install.sh | VIBEKE_VERSION=0.24.0 sh
```

Start `vibeke` in your project directory. If you already use Vibeke, run `vibeke update`. Open a new pane after updating the host.

## Browser and phone

Open [app.vibeke.dev](https://app.vibeke.dev). On your host, open **Devices** in the Vibeke terminal and select **Pair a phone**. You can also run:

```sh
vibeke gateway pair
```

Scan the code. Check the device fingerprint on both devices.

## Desktop updates

Open **Check for Updates…** in the desktop app to update a macOS, Windows EXE, or Linux AppImage installation. For a Linux DEB installation, download the new DEB. Windows may ask you to approve the installer because it has no publisher signature.
