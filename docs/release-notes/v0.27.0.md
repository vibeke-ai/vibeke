Vibeke 0.27.0 reduces the work that can delay typing and pane switching in busy terminal sessions.

## Typing and switching panes

- A background agent can check its screen for questions while you type in another pane.
- Scrollback search indexing releases the server lock between small batches. You can switch panes while a command produces a long log.
- The server captures a recovery point for a pane. A worker encodes it while the pane continues to handle input.
- The native terminal redraws changed rows for ordinary text updates. Large windows and split panes benefit when only one line changes.
- A Codex pane can look up its pending questions while the server reads another transcript.
- Pressing a key reads the keyboard setting it needs without copying the full configuration.

## Install or upgrade

The host CLI supports macOS 13 or later on Apple silicon and Intel. It also supports Linux on x86_64 and ARM64. Install `minisign` with your package manager, then run this command.

```sh
curl -fsSL https://vibeke.dev/install.sh | VIBEKE_VERSION=0.27.0 sh
```

Start `vibeke` in your project directory. If you already use Vibeke, run `vibeke update`.

## Browser and phone

Open [app.vibeke.dev](https://app.vibeke.dev). On your host, open **Devices** in the Vibeke terminal and select **Pair a phone**. You can also use this command.

```sh
vibeke gateway pair
```

Scan the code. Check the device fingerprint on both devices.

## Desktop updates

Open **Check for Updates…** in the desktop app to update a macOS, Windows EXE, or Linux AppImage installation. For a Linux DEB installation, download the new DEB. Windows may ask you to approve the installer because it has no publisher signature.
