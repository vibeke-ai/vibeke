Vibeke 0.26.0 improves typing and pane switching in the terminal interface on busy hosts.

## Typing and pane switching

Click a pane or use a pane shortcut to start typing there. A late screen update can no longer send the next key back to the previous pane. Vibeke accepts input while it saves the selection or waits for the host terminal to finish drawing.

A busy background pane now wakes only clients that display it. For ordinary ASCII output, the server updates only the rows that changed. It refreshes the full screen when text such as a combining accent needs it. Typing in a program that hides its input no longer causes a full repaint for each key.

The server sends fewer updates when it saves a draft or records agent history. Storage cleanup uses a separate database reader to find files still used by agent history.

## Install or upgrade

The host CLI supports macOS 13 or later on Apple silicon and Intel. It also supports Linux on x86_64 and ARM64. Install `minisign` with your package manager, then run this command.

```sh
curl -fsSL https://vibeke.dev/install.sh | VIBEKE_VERSION=0.26.0 sh
```

Start `vibeke` in your project directory. If you already use Vibeke, run `vibeke update`. This version upgrades the session database. Restore the backup made during the upgrade if you need to return to version 0.25.0.

## Browser and phone

Open [app.vibeke.dev](https://app.vibeke.dev). On your host, open **Devices** in the Vibeke terminal and select **Pair a phone**. You can also use this command.

```sh
vibeke gateway pair
```

Scan the code. Check the device fingerprint on both devices.

## Desktop updates

Open **Check for Updates…** in the desktop app to update a macOS, Windows EXE, or Linux AppImage installation. For a Linux DEB installation, download the new DEB. Windows may ask you to approve the installer because it has no publisher signature.
