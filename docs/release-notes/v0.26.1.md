Vibeke 0.26.1 fixes a cause of delayed typing and pane switching in sessions with long agent histories.

## Typing with long agent histories

After a server restart, Vibeke reads active agent transcripts to catch up. Earlier versions could search all recorded tool calls to find a single call. Typing and pane changes could pause for seconds while that search held the server lock.

Vibeke now uses a database index to find each tool call by its ID. Searches by handle also use an index. Existing sessions get the fix when the updated server starts.

## Install or upgrade

The host CLI supports macOS 13 or later on Apple silicon and Intel. It also supports Linux on x86_64 and ARM64. Install `minisign` with your package manager, then run this command.

```sh
curl -fsSL https://vibeke.dev/install.sh | VIBEKE_VERSION=0.26.1 sh
```

Start `vibeke` in your project directory. If you already use Vibeke, run `vibeke update`.

## Browser and phone

Open [app.vibeke.dev](https://app.vibeke.dev). On your host, open **Devices** in the Vibeke terminal and select **Pair a phone**. You can also use this command.

```sh
vibeke gateway pair
```

Scan the code. Check the device fingerprint on both devices.

## Desktop updates

Open **Check for Updates…** in the desktop app to update a macOS, Windows EXE, or Linux AppImage installation. For a Linux DEB installation, download the new DEB. Windows may ask you to approve the installer because it has no publisher signature.
